Build plan

How we would build this.

The stack the brief asked for, plus a job queue for the 24-hour catalogue sync and the 30-minute stock sync. Dates below are a proposed timeline, not a live schedule.

Proposed stack

Next.js (React) TypeScript Tailwind CSS Node.js PostgreSQL Prisma Job queue for cron

OAuth2 against identity.amrod.co.za/VendorLogin, with automatic Bearer token refresh. Parent products and child SKU variants upsert into PostgreSQL so the storefront does not hit API rate limits.

What you get on day one of each milestone

A working slice you can click, not a slide. The storefront follows the Brandability layout you named, with your own brand in place of this sample.

M1 · 3 weeks

Sync engine and catalogue

OAuth2 login and token refresh, full catalogue/image sync every 24 hours, live stock every 30 minutes, Prisma upserts, admin sync screen.

M2 · 3 weeks

Storefront and calculator

Mega-menu, faceted search, product page with swatches, size/stock matrix, tiered pricing, branding calculator, and the markup engine.

M3 · 2 weeks

Quote and checkout

Instant PDF quotes with 15% VAT, saved to admin, cart with artwork upload, courier rates, PayFast or Peach Payments.
